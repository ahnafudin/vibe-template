# Status archive — per-feature build history

Verbatim archive of `AGENTS.md` "Current state" stories. **The contract:** while a feature is
in flight, its detailed status (decisions, review findings, perf forensics, lessons) may grow;
once the work is MERGED and stable, move the full story HERE — verbatim, newest at the bottom —
and leave `AGENTS.md` with ≤ 1 short bullet per domain. `AGENTS.md` is auto-loaded every
session, so everything that stays there is a per-session context cost; this file is read
on demand only.

Any "NOT merged" / branch-name labels inside archived entries reflect the moment each
paragraph was written, not the present.

Read this before deep work on a domain whose history matters (performance work especially —
past forensics prevent re-fighting solved battles).
